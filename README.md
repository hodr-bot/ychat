# YChat — Telegram-style UI, SimpleX-grade privacy

Vision: best of Telegram UX with SimpleX protocol (no accounts, per-contact IDs, E2EE, SMP relays).
Non-negotiables: no phone/account, E2EE by default, random per-contact IDs, open source GPL-3.0, zero secrets committed, zero-cost infra (default SimpleX relays, user-modifiable list, no self-hosting in v0).

Roadmap:
- v0: fork/scaffold Android app renamed YChat, libsimplex backend via default SMP/XFTP servers, 1:1 chat + one-time link + long-term address, strip incompatible Telegram features.
- v1: @handle directory (resolve-only), groups, files.
- v2: calls, multi-device.
